# Machine Learning Journey

A hands-on repository documenting my journey learning Machine Learning, 
from Python and data manipulation to implementing fundamental ML algorithms 
and working with real-world datasets.

The goal of this repository is to understand the concepts behind machine 
learning algorithms by implementing and experimenting with them rather than 
only using high-level libraries.

---

## About This Repository

This repository contains my experiments, implementations, notebooks, and 
practice work while learning Machine Learning.

It currently covers:

- Python for Machine Learning
- NumPy
- Pandas
- Data Cleaning & Preprocessing
- Data Visualization
- Scikit-learn
- Supervised Learning
- Perceptron
- Classification
- Model Evaluation
- Feature Engineering
- Working with real datasets

The repository will continue to evolve as I learn new concepts and algorithms.
